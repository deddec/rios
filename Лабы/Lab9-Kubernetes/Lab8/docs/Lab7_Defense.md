## Связь с Paxos, Raft, Zab

| Модель ЛР | Raft | Paxos | Zab |
|---|---|---|---|
| Leader / Follower | Leader / Follower | Proposer (distinguished) / Acceptor | Leader / Follower |
| Эпоха `term` | term | номер предложения (ballot) | epoch |
| Выбор лидера по ID | выборы по таймауту и голосам | не требует лидера, но на практике выбирается (Multi-Paxos) | fast leader election |
| `Propose` → голоса → `Commit` | AppendEntries → quorum → commit | prepare/accept → quorum | proposal → ACK quorum → commit |
| Majority = N/2+1 | quorum | quorum | quorum |
| Индекс решения | log index | номер экземпляра (slot) | zxid |

Отличия модели: нет случайных таймаутов выборов и голосования за кандидата (лидер определяется по правилу
«максимальный ID»), нет репликации журнала по частям, отказ — только «узел молчит» (нет разделения сети и
византийских отказов). Это упрощённая модель, а не реализация алгоритмов.

## Контрольные вопросы (кратко)

1. **Консенсус** — согласованное решение узлов о значении состояния.
2. Нужен, чтобы узлы не принимали противоречивых решений при отказах.
3. **Leader** — узел, координирующий операцию: предлагает значения, собирает голоса, объявляет результат.
4. **Follower** — узел, отвечающий на heartbeat, голосующий и применяющий решения лидера.
5. **Leader election** — выбор узла-лидера (здесь: максимальный ID среди доступных).
6. При отказе лидера heartbeat не получает ответа → узел FAILED → повторные выборы → новый лидер.
7. **Heartbeat** — периодическая проверка «жив ли узел».
8. Узел недоступен, если не отвечает на heartbeat заданное число раз подряд.
9. **Majority** — N/2+1 узлов (5 → 3, 4 → 3).
10. Лидер предлагает значение, узлы отвечают YES/NO, решение принимается при YES ≥ Majority.
11. При равенстве голосов большинство не набрано — консенсуса нет, значение не применяется (тест `Voting_EqualSplit_IsNotConsensus`).
12. Лидер может остаться без большинства доступных узлов — тогда предложение не принимается (эксперимент 4).
13. Выбор лидера определяет, кто координирует; консенсус — что именно решено. Первое не гарантирует второе.
14. **Отказ узла** — узел перестал отвечать (остановка, обрыв связи).
15. **Paxos** — семейство протоколов консенсуса на основе предложений и подтверждения кворумом (proposer/acceptor/learner).
16. **Raft** — протокол консенсуса с явным лидером, эпохами, выборами и репликацией журнала.
17. **Zab** — протокол атомарной рассылки Apache ZooKeeper: упорядоченные изменения состояния от лидера с подтверждением кворумом.
